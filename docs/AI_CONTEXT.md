# AI Context

When editing this project:

- Follow the Figma exactly.
- Do not redesign sections unless asked.
- Preserve the existing folder structure.
- Keep one component per file.
- Keep one CSS file per component/page.
- Use semantic HTML.
- Use functional React components.
- Keep CSS clean and readable.
- Prefer Flexbox unless Grid is clearly better.
- Do not rename components without permission.
- Do not introduce unnecessary libraries.
- Generate code that is easy to review.
- Keep commits focused on one feature at a time.
